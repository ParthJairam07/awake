Pair with your Mac

On the Mac, open Awake's Settings, go to Phone app and choose Pair phone…. Type the 6-digit code it shows.

The code works once, for five minutes. This phone then keeps a key that only this Mac accepts; "Forget" in Awake's Settings takes it away.
